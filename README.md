# Creaciones y Detalles Stefy

Esta es una primera versión experimental de la web, hecha en cloud para que se pueda ver sin ocupar espacio en tu máquina.

Qué tiene por ahora:
- Nombre: Creaciones y Detalles Stefy
- Toque cercano y sencillo
- Sección de catálogo con galería libre por temas:
  - Muñecos
  - Muñecos navideños
  - Juegos para baños
  - Detalles personalizados
- Sección de cómo poner un pedido
- Contacto principal por WhatsApp

Qué aún falta:
- Fotos reales
- Textos reales
- Posible ajuste de colores o estilo
- Número de WhatsApp real y texto de mensaje de entrada

Cómo verlo:
- Abre el preview que dice la herramienta cuando esté listo, o servelo con un servidor local si lo prefieres.
- Si quieres, puedo ayudarte a ajustar lo que veas antes de meter las fotos.

Próximos pasos posibles:
- Reemplazar las imágenes provisional por las fotos de tus productos
- Ajustar el texto de contacto y el mensaje que llega por WhatsApp
- Cambiar colores o relocate cosas si no te gusta el orden
- Agregar más secciones si hace falta

Esta versión es solo para revisar el diseño. Cuando tengamos las fotos y los textos reales, los actualizamos.
